# よろずオープナー 配布物

開かないファイルも、たいてい開く。書き込みも、押印も。
電脳よろず屋 / 株式会社ダブルピース の無料ソフト「よろずオープナー」の配布用置き場です。

## ダウンロード

**[インストーラー版 1.7.11(おすすめ・約12MB)](https://github.com/dontacos0321/yorozu-opener-releases/raw/main/app/YorozuOpener_Setup_1.7.11.exe)**
ダウンロードして実行し、「次へ」で進めるだけです。管理者の権限は要りません。
スタートメニューとデスクトップに登録され、Windows の「設定 → アプリ」から削除できます。

[ZIP版 1.7.11(インストールしたくない方向け・約19MB)](https://github.com/dontacos0321/yorozu-opener-releases/raw/main/app/YorozuOpener_1.7.11.zip)
展開して、`amd64` フォルダ(ふつうのパソコン)の `YorozuOpener.exe` を起動してください。ARM のパソコンは `arm64` のほうです。

初回は Windows の青い画面(「PC が保護されました」)が出ることがあります。「詳細情報」→「実行」で進めてください。

## この置き場について
- アプリ内の「アップデートがあります」の確認(`latest.json`)と、画像編集のAI部品(`ai/`)のダウンロードは、ここから行われます
- AI部品はパソコンの中だけで動きます。編集する画像がどこかへ送られることはありません
- ソースコードはここにはありません
