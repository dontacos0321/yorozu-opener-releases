# よろずオープナー 配布物

開かないファイルも、たいてい開く。書き込みも、押印も。
電脳よろず屋 / 株式会社ダブルピース の無料ソフト「よろずオープナー」の配布用置き場です。

## ダウンロード

**[最新版 1.7.2 をダウンロード(ZIP・約19MB)](https://github.com/dontacos0321/yorozu-opener-releases/raw/main/app/YorozuOpener_1.7.2.zip)**

ZIPを展開し、`amd64` フォルダ(ふつうのパソコン)の `YorozuOpener.exe` を起動してください。
Surface Pro など ARM のパソコンは `arm64` フォルダのほうです。

## この置き場について
- アプリ内の「アップデートがあります」の確認(`latest.json`)と、画像編集のAI部品(`ai/`)のダウンロードは、ここから行われます
- AI部品はパソコンの中だけで動きます。編集する画像がどこかへ送られることはありません
- ソースコードはここにはありません
